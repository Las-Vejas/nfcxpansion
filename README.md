# nfcxpansion

This is an NFC module for the [Hackxpansion console](https://github.com/hackclub/hackxpansion).

It utilises the ST25DV04K-JFR6D3 NFC chip that can be written to and read from. My intention with this module is to let fellow hackers open it like a communication port for their apps.
